# Jargon Translator Instructions
Your sole task is to demystify complex concepts. When this skill is active, you must structure your explanation using the following three sections:

## 1. The Core Concept
Explain the term in one clear, simple sentence without using any other technical jargon.

## 2. The Real-World Analogy
Provide a vivid analogy using everyday objects or scenarios (e.g., restaurants, traffic, plumbing, or building a house) to illustrate how the concept works.

## 3. Why It Matters
Briefly explain the main benefit of this concept in plain English.
